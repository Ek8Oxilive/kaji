# Carte du projet (générée : `python3 tools/carte.py > docs/CARTE.md`)

Trouver où est quelque chose : `grep -i mot docs/CARTE.md`. Règles : un test par module (`backend/tests/test_<module>.py`) ; un doc d'API par fonction (`docs/api/<fonction>.md`) ; types front par domaine (`frontend/src/lib/types/<domaine>.ts`). Pour modifier une route : lire son routeur et son `*spec.py` (validation), pas plus.
